Политика конфиденциальности

Приложение «Русский собеседник». Текст от 16 ноября 2026 года.

Коротко

  • Приложение работает без регистрации.
  • Ваш прогресс, настройки и имя хранятся только на вашем телефоне.
  • Приложение не собирает ваши личные данные и не показывает рекламу.

1. Кто отвечает за приложение

Приложение сделал один человек — автор и разработчик Сафармамадов Фарход.

Написать автору можно из приложения: «Ещё» → «О приложении» → «Написать автору».

2. Что хранится на вашем телефоне

  • Прогресс: пройденные уроки, слова для повторения, результаты заданий.
  • Настройки: язык, оформление, размер шрифта, голос, сколько минут в день заниматься.
  • Имя, если вы его написали. Имя можно не писать.
  • Технический журнал: какие уроки и задания вы открывали и какие ошибки были в приложении. В журнале нет вашего имени, номера телефона и адреса.

Всё это лежит в памяти браузера на вашем телефоне. Автор не получает эти данные.

3. Чего приложение не делает

  • Не просит регистрироваться, не спрашивает номер телефона и электронную почту.
  • Не записывает ваш голос и не включает микрофон.
  • Не узнаёт, где вы находитесь.
  • Не читает ваши контакты, фотографии и сообщения.
  • Не показывает рекламу и не передаёт данные рекламным компаниям.
  • Не использует счётчики посещений и программы слежения.

4. Что передаётся через интернет

  • Телефон скачивает файлы приложения, уроки и звук с сайта приложения. Сайт находится на сервисе GitHub Pages (компания GitHub, США). Когда телефон скачивает файлы, GitHub записывает IP-адрес телефона, чтобы защищать свои серверы. Это делает GitHub, а не автор приложения. Политика конфиденциальности GitHub (на английском)
  • Письмо автору. Если вы нажмёте «Сообщить о проблеме» или «Написать автору», откроется ваша почтовая программа. В письме будут: ваш текст, версия приложения, название браузера и системы телефона, язык приложения. Технический журнал добавляется, только если вы сами это отметите. Письмо уходит, только когда вы нажмёте «Отправить». Автор увидит адрес вашей электронной почты и использует его только для ответа вам.
  • Кнопка «Поделиться ссылкой» открывает окно телефона для отправки ссылки. Кому отправить ссылку, решаете вы.

5. Датчик движения

В оформлении «Чаша» чаша может качаться, когда вы наклоняете телефон. Для этого приложение использует датчик движения. Данные датчика не сохраняются и никуда не передаются. Это можно выключить в настройках.

6. Голос телефона

Фразы уроков записаны заранее и лежат в файлах приложения. Если записи нет, фразу читает голос вашего телефона (синтезатор речи). Как он работает, зависит от телефона и его настроек.

7. Как удалить данные

  • В приложении: «Ещё» → «Удалить мой прогресс».
  • Или очистите данные этого сайта в настройках браузера.

После удаления восстановить данные нельзя: копии у автора нет.

8. Дети

Приложение сделано для взрослых. Оно не собирает данные ни взрослых, ни детей.

9. Если политика изменится

Если в приложении появятся новые функции — например, сохранение прогресса в интернете или запись вашего голоса, — эта страница изменится раньше, чем они появятся. Наверху будет новая дата.

Сиёсати махфият

Барномаи «Русский собеседник». Матни 16 ноябри соли 2026.

Мухтасар

  • Барнома бе бақайдгирӣ кор мекунад.
  • Пешрафт, танзимот ва номи шумо танҳо дар телефони шумо нигоҳ дошта мешаванд.
  • Барнома маълумоти шахсии шуморо ҷамъ намекунад ва реклама нишон намедиҳад.

1. Барои барнома кӣ ҷавобгар аст

Барномаро як нафар сохтааст — муаллиф ва таҳиягар Сафармамадов Фарҳод.

Ба муаллиф аз худи барнома навиштан мумкин аст: «Бештар» → «Дар бораи барнома» → «Ба муаллиф навиштан».

Почтаи муаллиф:

2. Дар телефони шумо чӣ нигоҳ дошта мешавад

  • Пешрафт: дарсҳои хондашуда, калимаҳо барои такрор, натиҷаи супоришҳо.
  • Танзимот: забон, намуди зоҳирӣ, андозаи ҳарфҳо, овоз, дар як рӯз чанд дақиқа дарс хондан.
  • Ном, агар шумо онро навишта бошед. Номро нанавиштан ҳам мумкин аст.
  • Журнали техникӣ: кадом дарсу супоришҳоро кушодед ва дар барнома чӣ хатоҳо шуданд. Дар журнал ном, рақами телефон ва суроғаи шумо нест.

Ҳамаи ин дар хотираи браузери телефони шумо нигоҳ дошта мешавад. Муаллиф ин маълумотро намегирад.

3. Барнома чӣ корҳоро намекунад

  • Бақайдгирӣ талаб намекунад, рақами телефон ва почтаи электрониро намепурсад.
  • Овози шуморо сабт намекунад ва микрофонро фаъол намекунад.
  • Дар куҷо будани шуморо муайян намекунад.
  • Контактҳо (рақамҳои телефон), суратҳо ва паёмҳои шуморо намехонад.
  • Реклама нишон намедиҳад ва маълумотро ба ширкатҳои рекламавӣ намедиҳад.
  • Ҳисоб намекунад, ки кӣ чанд бор даромадааст, ва барномаҳои назораткунандаро истифода намебарад.

4. Тавассути интернет чӣ интиқол меёбад

  • Телефон файлҳои барнома, дарсҳо ва садоро аз сайти барнома боргирӣ мекунад. Сайт дар хидмати GitHub Pages (ширкати GitHub, ИМА) ҷойгир аст. Вақте ки телефон файлҳоро боргирӣ мекунад, GitHub барои ҳифзи серверҳои худ суроғаи IP-и телефонро сабт мекунад. Инро GitHub мекунад, на муаллифи барнома. Сиёсати махфияти GitHub (ба забони англисӣ)
  • Мактуб ба муаллиф. Агар шумо «Хабар додан дар бораи мушкил» ё «Ба муаллиф навиштан»-ро пахш кунед, барномаи почтаи шумо кушода мешавад. Дар мактуб инҳо навишта мешаванд: матни шумо, версияи барнома, номи браузер ва системаи телефон, забони барнома. Журнали техникӣ танҳо вақте илова мешавад, ки худатон инро қайд кунед. Мактуб танҳо пас аз пахш кардани «Фиристодан» фиристода мешавад. Муаллиф суроғаи почтаи электронии шуморо мебинад ва онро танҳо барои ҷавоб додан ба шумо истифода мебарад.
  • Тугмаи «Ирсоли истинод» равзанаи телефонро барои фиристодани истинод мекушояд. Истинодро ба кӣ фиристодан — худатон ҳал мекунед.

5. Датчики ҳаракат

Дар намуди «Пиёла» пиёла ҳангоми каҷ кардани телефон метавонад биҷунбад. Барои ин барнома аз датчики ҳаракат маълумот мегирад. Маълумоти датчик нигоҳ дошта намешавад ва ба ҳеҷ ҷо фиристода намешавад. Инро дар танзимот хомӯш кардан мумкин аст.

6. Овози телефон

Ибораҳои дарсҳо пешакӣ сабт шудаанд ва дар файлҳои барнома ҳастанд. Агар сабт набошад, ибораро овози телефони шумо (синтезатори нутқ) мехонад. Тарзи кори ин овоз ба телефон ва танзимоти он вобаста аст.

7. Маълумотро чӣ тавр нест кардан мумкин аст

  • Дар барнома: «Бештар» → «Пешрафти маро нест кардан».
  • Ё маълумоти ин сайтро дар танзимоти браузер тоза кунед.

Пас аз нест кардан маълумотро барқарор кардан мумкин нест: муаллиф нусха надорад.

8. Кӯдакон

Барнома барои калонсолон сохта шудааст. Он маълумоти калонсолонро ҳам, кӯдаконро ҳам ҷамъ намекунад.

9. Агар сиёсати махфият тағйир ёбад

Агар дар барнома имкониятҳои нав пайдо шаванд — масалан, нигоҳдории пешрафт дар интернет ё сабти овози шумо, — ин саҳифа пеш аз пайдо шудани онҳо тағйир меёбад. Дар боло санаи нав навишта мешавад.
