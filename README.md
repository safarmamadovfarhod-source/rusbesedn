# Русский собеседник — приложение (PWA), версия 0.2.0

Работает в браузере Chrome на Android и устанавливается на главный экран; после первой загрузки работает без интернета.
Всё хранится на телефоне (localStorage). Регистрации нет. Голос и персональные данные не собираются.

## Как запустить на своём компьютере (проверка)
```
cd app
python3 tools/build_manifest.py      # собирает sw.js (офлайн) и обновляет сведения об озвучке
python3 -m http.server 8765          # затем открыть http://localhost:8765 в Chrome
```
Установка как приложение: меню Chrome → «Установить приложение». Установка и офлайн-режим работают на `localhost` и на любом адресе `https://`.

## Как выложить для участников пилота (бесплатно, GitHub Pages)
1. Создайте на GitHub репозиторий (например `rusbesedn`), загрузите в него **содержимое папки app** (без папок `tests` и `tools`, их можно оставить).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Через 1–2 минуты приложение будет по адресу `https://<ваш-логин>.github.io/rusbesedn/`.
3. Отправьте участникам эту ссылку и инструкцию установки из `stage5-pilot-kit.md`.
Каждый раз, когда меняете файлы: запустите `python3 tools/build_manifest.py` (меняет версию в `sw.js`), загрузите изменения. Телефоны обновятся при следующем открытии.

## Как добавить урок без программирования
1. Положите файл урока в `data/lessons/<id>/lesson.json` (структура — как у `a0_01`), озвучку — в `data/lessons/<id>/audio/` (`<id>_timings.json` и файлы `.mp3/.ogg`, их даёт `make_audio.py`).
2. Добавьте строку урока в `data/courses.json` (поле `path`; `"soon": true` убирается).
3. `python3 tools/validate_lesson.py data/lessons/<id>/lesson.json` — должны быть «ошибок 0».
4. `python3 tools/build_manifest.py`.
(В версии 0.2.0 приложение загружает первый урок с `path`; список уроков и переключение между несколькими уроками — задача версии 0.3.)

## Адрес для «Сообщить о проблеме»
В `js/config.js` поле `REPORT_TO`. Пусто → приложение предлагает скопировать текст. Если указать адрес, откроется письмо в почте пользователя (отправляет сам пользователь).

## Проверки
```
node --test tests/unit.mjs tests/i18n.test.mjs     # 20 автотестов
python3 tools/validate_lesson.py                    # проверка формата урока
```

## Структура
`index.html`, `manifest.webmanifest`, `sw.js` (генерируется), `css/`, `js/` (модули и экраны), `data/` (i18n, курсы, диагностика, уроки), `fonts/` (PT Sans, лицензия OFL), `icons/`.
Версия приложения: `js/config.js` (`APP_VERSION`).
