# Русский собеседник — приложение (PWA), версия 0.4.0

Учит русскому языку таджикоговорящих. Работает в Chrome на Android и в Safari на iPhone, ставится на главный экран, после первой загрузки работает без интернета. Сервера нет: всё хранится на телефоне (localStorage), регистрации нет, голос и личные данные не собираются.

Сейчас в приложении 8 уроков: путь A «с основ» — 5 (Знакомство, Семья, Магазин, Транспорт, Работа), путь B «Знаю русский» — 3. Все уроки — черновики: русский текст ждёт методиста РКИ, таджикский — носителя.

История версий — в `CHANGELOG.md`. Отчёты, восстановленные принципы и журнал решений — в папке `docs/` (список в `docs/otchety.md`).

## 1. Запуск на компьютере (2 минуты)
Нужны Python 3 и Chrome. Команды выполняются в папке приложения (там, где лежит `index.html`).
```
python3 tools/build_manifest.py      # собирает sw.js (список файлов для работы без интернета) и сведения об озвучке
python3 -m http.server 8765          # затем открыть http://localhost:8765 в Chrome
```
Установка как приложение: меню Chrome → «Установить приложение». Установка и работа без интернета доступны на `localhost` и на любом адресе `https://`.

## 2. Проверки (3 минуты)
```
node --test tests/unit.mjs tests/i18n.test.mjs      # модульные тесты (нужен Node 18+)
python3 tools/validate_lesson.py data/lessons/a0_01/lesson.json   # формат урока: «ошибок 0»
python3 -m http.server 8765 &
python3 tests/e2e_smoke.py http://localhost:8765/   # проверки экранов в Chromium (нужен пакет playwright)
```
Тесты проверяют приложение в браузере на компьютере (экран 360×640). На реальных Android и iPhone приложение проверяет человек.

## 3. Как устроен код (5 минут)
Сборщика и внешних библиотек нет: браузер загружает модули JavaScript как есть.

| Файл или папка | Что там |
|---|---|
| `index.html`, `css/app.css` | Одна страница и все стили. Три оформления — через `data-theme` на `<html>` и переменные CSS |
| `js/main.js` | Запуск, переходы между экранами (`app.go`, `app.back`), кнопка «назад» телефона, заставка |
| `js/app.js` | Общий объект `app`: таблица экранов `app.R` и действий `app.ACT` |
| `js/screens/*.js` | Экраны. Каждый экран — функция `R.<имя>()`, которая возвращает HTML строкой; нажатия — `ACT.<имя>` по атрибуту `data-act` |
| `js/store.js` | Состояние `S` и сохранение в localStorage (ключ `rs_state_v1`), экспорт и импорт файла прогресса |
| `js/content.js` | Список курсов, загрузка уроков по требованию (`ensureLesson`, `useLesson`), «текущий урок», поиск слов и разборов |
| `js/audio.js` | Звук: файл озвучки → голос телефона → без звука (только подсветка) |
| `js/srs.js`, `js/progress.js` | Интервальное повторение (1, 3, 7, 14 дней), серия дней, цель недели |
| `js/i18n.js`, `data/i18n.json` | Тексты интерфейса на русском и таджикском |
| `js/analytics.js` | Журнал событий: только на телефоне, без личных данных |
| `js/config.js` | Версия, адрес поддержки, флаг `DEV_PANEL` |
| `data/courses.json` | Список курсов и уроков (пути A и B) |
| `data/lessons/<id>/lesson.json` | Урок: слова, диалог, «Почему так?», упражнения, сценарий диалога |
| `data/grammar.json`, `data/glossary.json` | Вкладка «Грамматика» и словарь терминов |
| `sw.template.js` → `sw.js` | Работа без интернета. `sw.js` создаёт `tools/build_manifest.py`, руками его не правят |
| `tools/` | `build_manifest.py` (сборка), `validate_lesson.py` (проверка урока), `make_audio.py` (озвучка на компьютере автора) |
| `tests/` | Модульные тесты и проверки экранов |
| `docs/`, `audit-experiments/` | Документы проекта и временные опыты. В приложение не входят, на хостинг их можно не загружать |

Как проходит нажатие: кнопка с `data-act="exans"` → обработчик в `js/main.js` находит `app.ACT.exans` → функция меняет состояние и вызывает `app.render()` → экран рисуется заново.

### Как загружаются уроки (с 0.3.10)
- При запуске загружается список `data/courses.json` и один урок — тот, что человек откроет следующим. Два следующих урока пути подгружаются в фоне.
- Остальные уроки загружаются при открытии: `app.useLesson(id)`. Нет сети и урока нет в кэше → сообщение «Этот урок ещё не скачан».
- В `courses.json` у каждого урока есть сводка `sum` (заголовок диалога, «Я могу…», список слов) и версия `v` (хэш файлов урока). Их пишет `tools/build_manifest.py`. Версия стоит в адресе файла (`lesson.json?v=…`), поэтому изменённый урок скачивается заново, а неизменённый — никогда.
- Сервис-воркер держит два кэша: оболочку (`rs-<версия>`, заменяется при обновлении) и уроки с озвучкой (`rs-lessons-1`, переживает обновления).
- Озвучка открытого урока (оба голоса, обычный темп) скачивается в фоне, чтобы урок звучал без интернета. Проверено на файлах-заглушках; с настоящей озвучкой не проверено.

## 4. Настройки в `js/config.js`
- `APP_VERSION` — номер версии (показывается в «О приложении»).
- `REPORT_TO` — адрес для «Сообщить о проблеме». Пусто → приложение предлагает скопировать текст. Сейчас там личная почта автора: перед публикацией заменить на адрес поддержки.
- `SUPPORT_TG` — ссылка на Telegram поддержки (`https://t.me/…`). Пусто → кнопки нет.
- `DEV_PANEL` — `true` только у разработчика: в «Ещё» появляется панель «Для проверки», под уроком — служебные пометки. В сборке для людей — `false`.

## 5. Как добавить урок без программирования
1. Положите файл урока в `data/lessons/<id>/lesson.json` (образец — `a0_01` для пути A или `b_01` для пути B).
2. Озвучка (если есть): `data/lessons/<id>/audio/<f|m>/<n|s>/<id реплики>.mp3` и файлы `<id>_timings_<f|m>_<n|s>.json` (4 набора: голос × темп).
3. Добавьте строку урока в `data/courses.json` (поле `path`; пометка `"soon": true` убирается).
4. `python3 tools/validate_lesson.py data/lessons/<id>/lesson.json` — должно быть «ошибок 0».
5. `python3 tools/build_manifest.py`.

### Озвучка (Yandex SpeechKit, на компьютере автора)
`tools/make_audio_yandex.py` озвучивает все уроки голосами Лера и Кирилл в двух темпах. Нужен ключ API Yandex Cloud; ключ остаётся у автора. Скрипт берёт уроки из папки `lessons` рядом с собой и собирает архив `ozvuchka.zip` с папками `audio`. Их кладут в `data/lessons/<id>/audio/` и запускают `tools/build_manifest.py`. На 8 уроков — 1046 запросов.

### Поле `names` в уроке
Имена людей в диалоге, кроме Шароры и Манучехра, перечисляют в `lesson.json` → `"names": ["фирдавс", "мадина"]` (строчными, без ударения): при нажатии на имя приложение покажет «Имя человека».

## 6. Как выложить (бесплатно, GitHub Pages)
1. Загрузите в репозиторий содержимое папки приложения (папки `tests` и `tools` можно оставить; `docs` и `audit-experiments` загружать не нужно).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Через 1–2 минуты приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.
3. После каждого изменения файлов: `python3 tools/build_manifest.py` (меняет версию в `sw.js`) и загрузка. Телефоны обновятся при следующем открытии.

**iPhone:** открыть ссылку именно в Safari → «Поделиться» → «На экран „Домой“». На реальном iPhone не проверено.

## 7. Что не проверено и не сделано
- Реальные телефоны (дешёвый Android, старый Android, iPhone), звук на слух.
- Таджикские тексты — черновик, нужна проверка носителем; уроки — проверка методистом РКИ.
- Записанной озвучки нет: звучит голос телефона. Скрипт и уроки для озвучки готовы.
- Во вкладке «Грамматика» тем для уроков 2–5 пути A пока нет.
- Упаковка для Google Play и RuStore, веб-страница политики конфиденциальности.
